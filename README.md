# 🚀| Portal de Oportunidades Favela Tech

## 📖 Descrição do Projeto

O **Portal de Oportunidades Favela Tech** é uma plataforma web desenvolvida com foco no ODS 8 — Trabalho Decente e Crescimento Econômico.

O objetivo é conectar jovens capacitados a empresas locais, promovendo inclusão profissional, qualificação e geração de oportunidades.

A plataforma permite que usuários criem seus perfis, cadastrem currículos, busquem vagas e recebam recomendações automáticas com base em suas habilidades.

---

## 🎯| Objetivos

- Facilitar o acesso ao mercado de trabalho
- Conectar jovens talentos a empresas
- Incentivar capacitação profissional
- Promover crescimento econômico local

---

## 🛠️| Tecnologias Utilizadas

- **HTML5** – Estrutura do site  
- **CSS3** – Estilização, responsividade e animações  
- **JavaScript** – Interatividade e manipulação do DOM  
- **APIs externas** – Integração com plataformas de vagas  
- **Chatbot** – Assistente virtual para suporte ao usuário  
- **Banco de Dados** – Armazenamento de usuários e vagas
